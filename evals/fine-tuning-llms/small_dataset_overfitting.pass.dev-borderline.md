Overfitting is not a risk you can ignore with 40 examples: a 7B model with LoRA can memorize them within a couple of epochs. First try few-shot prompting with those examples in context; at this size it often matches a fine-tune. If you still fine-tune, use a low rank (r=4 or 8), 1-3 epochs with early stopping, and hold out 8-10 examples as a validation set so you can see when eval loss turns up. Collecting more labeled data will help more than any hyperparameter.
