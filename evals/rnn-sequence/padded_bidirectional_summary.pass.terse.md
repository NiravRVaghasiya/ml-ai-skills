output[:, -1] is a padding position for every sentence shorter than the batch maximum: the forward half has run over pad tokens and the backward half has seen only padding. Use pack_padded_sequence(x, lengths.cpu(), batch_first=True, enforce_sorted=False) and build the representation from the top layer of h_n: torch.cat([h_n[-2], h_n[-1]], dim=-1). batch_first does not change h_n's layout (num_layers * 2, batch, 128). If you read from output instead, use the pad_packed_sequence output of the packed run: forward half at lengths-1, backward half at output[:, 0, 128:]. On the unpacked output of a 2-layer bidirectional GRU no position is clean, since the top forward layer consumes bottom-layer backward states that have seen the padding.
