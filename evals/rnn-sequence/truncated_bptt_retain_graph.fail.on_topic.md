The hidden state you carry over from the previous chunk is still attached to that chunk's graph, which is why backward wants to go through it again. You could detach it, but detaching cuts the gradient flow between chunks and the LSTM would lose its ability to learn long-range dependencies. So keep retain_graph=True and fix the in-place error instead: clone the weights before optimizer.step() (or call optimizer.step() once at the end of the full sequence) so the saved tensors stay valid.
