Undo retain_graph=True - it masked the real problem. Your (h, c) from chunk k is part of chunk k's graph, so chunk k+1's backward follows it into a graph that was already freed. Detach the hidden state before each new chunk (h = h.detach(); c = c.detach()). With retain_graph the earlier graph is kept, backward goes through all previous chunks, and since optimizer.step() modified the parameters in place, the saved weights are stale, which is the second error.
