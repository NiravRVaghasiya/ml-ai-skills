Remove retain_graph=True and detach the LSTM state between chunks: `h, c = h.detach(), c.detach()` before feeding them into the next chunk. The original error comes from the carried (h, c) still pointing into the previous chunk's graph. retain_graph only keeps that old graph alive, so backward walks through all earlier chunks, and since optimizer.step() changed the weights in place, the old graph's saved tensors are invalid - hence the new error. Detaching preserves the values (the forward context) but truncates the gradient at the boundary, which is the point of truncated BPTT.
