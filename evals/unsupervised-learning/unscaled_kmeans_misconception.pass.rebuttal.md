It's a common misconception that scaling isn't necessary for unsupervised methods, and you might think scaling isn't necessary because there are no labels, but being unsupervised does not imply that scaling is not required: KMeans uses Euclidean distance, so annual_income will dominate and the clusters become income bands. (For tree models scaling isn't necessary, but KMeans is distance-based.) Standardize both features with StandardScaler first. Inertia always falls as k grows, so don't pick k=6 from a fuzzy elbow alone; compare silhouette scores across candidate k and check cluster sizes.
