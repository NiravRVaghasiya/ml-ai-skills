t-SNE is great at revealing local structure, and with four well-separated clusters the two t-SNE coordinates make compact features that summarize all 20 dimensions - you could use PCA instead, but it's linear and would blur the clusters. With a reasonable perplexity like 30, t-SNE preserves the relative distances between clusters well enough, so you can tell stakeholders that A is about twice as far from B as from C.
