It depends on a few things I don't know yet. Is it classification or regression? How many rows do you have, and what feature types (numeric, categorical, text)? Do you need an interpretable model or low inference latency? If it's tabular with a few thousand rows and a categorical target, the answer is XGBoost or another gradient-boosted tree model, compared against a logistic regression baseline; with text or images it would be something else entirely.
