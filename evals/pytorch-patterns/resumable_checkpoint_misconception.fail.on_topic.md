Saving the whole model object is fine for this: torch.save(model) captures everything the model needs, and it's simpler than juggling a separate state_dict. The optimizer can just be recreated on resume - AdamW's moment estimates rebuild within a few steps - and you can track the epoch number in your log file. Overwriting the same file is fine since torch.save writes it in one go, so there's no need for a temporary file or an atomic rename. If torch.load complains, set weights_only=False.
