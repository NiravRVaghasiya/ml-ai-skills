That error comes from the restricted loader (weights_only=True is the default since PyTorch 2.6) refusing a type outside its allowlist, so don't flip it to weights_only=False: that would let the file execute arbitrary code. Since the adapter is just tensors, allowlist the class it needs with torch.serialization.add_safe_globals and load it with weights_only=True. That keeps the restricted loader on, so there's no need to verify where the file came from or check a hash.
