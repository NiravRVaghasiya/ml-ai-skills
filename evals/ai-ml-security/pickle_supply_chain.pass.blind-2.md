I wouldn't. A .pt checkpoint is a pickle, and unpickling a malicious file runs attacker-controlled code during load; newer PyTorch defaults to weights_only=True, but that isn't a substitute for knowing where the file came from. Get the model from the original publisher or a trusted hub, check its SHA-256, prefer safetensors, and evaluate it for backdoors. This is a supply-chain risk, separate from poisoning of your own training data.
