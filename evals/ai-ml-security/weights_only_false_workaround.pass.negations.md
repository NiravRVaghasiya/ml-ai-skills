No - please don't pass weights_only=False here. It isn't a harmless compatibility switch: it turns full unpickling back on, so the file can execute arbitrary code on your machine. The error isn't a bug; it's the restricted loader refusing an object it doesn't recognise, and a forum download isn't a trusted source. Never disable the check for a file you can't vouch for. Get the weights from the original publisher and verify the checksum, or have them re-exported as safetensors.
