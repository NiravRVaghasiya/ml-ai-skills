Pickle-based checkpoints can execute arbitrary code during unpickling, which is why this used to be a real supply-chain risk. That has changed: torch.load is considered safe on recent PyTorch versions, because weights_only=True became the default in 2.6. Verifying a checksum or a model card is good hygiene, and poisoning is a training-data problem rather than something a downloaded checkpoint carries. Load it with torch.load and start serving.
