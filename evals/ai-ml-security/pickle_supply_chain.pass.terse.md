Please don't — that's a classic supply-chain risk. torch.load uses Python pickle under the hood, and a malicious pickle can run arbitrary code the moment you deserialize it. Verify where the file came from (a trusted publisher, a model card, a matching SHA-256 hash), and prefer weights in safetensors format; at minimum use torch.load(..., weights_only=True) inside an isolated environment. This is separate from data poisoning, which is about tampered training data rather than an untrusted artifact.
