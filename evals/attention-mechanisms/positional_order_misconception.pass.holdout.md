Not quite. Self-attention without positions is permutation-equivariant (permuting inputs permutes outputs), not invariant. More importantly, a decoder-only model uses a causal mask, and the mask itself breaks the symmetry: token i can only attend to tokens 0..i, so the number of visible tokens encodes position implicitly. Haviv et al. (2022) showed causal language models without positional encodings (NoPE) still learn order and get competitive perplexity. A bidirectional encoder without positional information would be the order-blind case.
