No. FlashAttention computes exact attention, just in an IO-aware tiled way that never materializes the n x n score matrix in HBM. That cuts the extra memory from quadratic to linear in n and gives large wall-clock speedups, but the FLOPs are still O(n^2 d), so compute still grows quadratically with context length. Sparse, linear and other sub-quadratic approaches still matter at very long contexts; FlashAttention is complementary and is often combined with them.
