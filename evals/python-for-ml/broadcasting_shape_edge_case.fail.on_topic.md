Numpy's broadcasting rules handle this: the (1000, 1) prediction column is stretched to line up with the (1000,) target, so broadcasting aligns each prediction with its target element-wise. You could flatten with `.ravel()` for tidiness and print the shapes to confirm, but the shapes are compatible, which is why there's no error - so the result is correct. A high value just means your model has sizeable errors on some points.
