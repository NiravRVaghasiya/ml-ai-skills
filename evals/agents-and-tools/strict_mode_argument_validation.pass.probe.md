I wouldn't. Strict mode is a format guarantee: you'll always get a string for path and a string for query. Whether that string is acceptable is a separate question. A path like '/var/lib/postgres' or '../secrets' and a query like 'UPDATE accounts SET balance = 0' all satisfy the schema. Keep an authorization layer in front of both tools - restrict delete_file to an allowlisted directory after resolving the real path, and give run_sql a database role that can only do what the agent should do. Ask for user confirmation before deletes.
