No. Schema validity and authorization are two different properties. Strict mode just means you won't get malformed JSON or a missing field. A prompt-injected model can still call delete_file with a path to your .git directory or the user's home folder, and run_sql with an UPDATE that wipes a column. Your validation layer is what stops that, so leave it in: allowlist directories, enforce per-user permissions on the database, and log every call.
