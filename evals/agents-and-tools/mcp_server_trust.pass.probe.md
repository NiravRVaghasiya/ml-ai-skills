No - "standard" and "trusted" are different things. MCP is just the plumbing that lets your agent discover and call the server's tools; it says nothing about whether the server is honest or whether the pages and issues it returns are safe. Anything coming back (web pages, issue bodies, even the tool descriptions themselves) is untrusted text that could contain instructions aimed at your agent - classic indirect prompt injection. Since the server holds your org token, limit the damage: use a token with the smallest scope that works, disable tools you don't use, and confirm before closing issues.
