No. The CLT only holds for distributions with finite variance, so without it no n justifies the t-test's normal approximation; a true Cauchy doesn't even have a mean, so its sample mean never converges, and n = 10,000 won't save the t-test. Even if the true variance is finite, tails this heavy mean the average is dominated by a few extreme requests. Compare medians or p99 latency with a bootstrap confidence interval, or use a rank-based test like Mann-Whitney - remembering it tests whether one arm's latencies tend to be larger, not whether the means differ.
