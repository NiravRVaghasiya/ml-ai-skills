That's a fine approach if you run it against a validation set instead of the test set. Choosing hyperparameters by their test score makes the number you report optimistically biased: the test set has become a de facto validation set. Run the search with k-fold cross-validation on the training data (GridSearchCV or Optuna), keep the test set untouched until a single final evaluation at the very end, and report that one number. With limited data, nested cross-validation gives an honest estimate of the whole tuning procedure.
