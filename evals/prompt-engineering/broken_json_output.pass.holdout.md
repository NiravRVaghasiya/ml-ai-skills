Prompting alone won't get you to zero; temperature 0 doesn't guarantee well-formed output either. Use the API's structured output feature (JSON mode / a response schema, or force a tool call whose input schema is your schema) so decoding is constrained. Then validate every response against the schema in code (e.g. jsonschema or Pydantic) and on failure retry once with the validation error appended. Also check the stop reason: hitting max_tokens truncates JSON mid-object, and a refusal won't be JSON at all, so handle both explicitly.
