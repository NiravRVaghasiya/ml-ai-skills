No. Tags plus an instruction reduce the risk but don't eliminate it; the model reads everything as tokens, and a document can still contain text that persuades it, or a forged </document> closing tag. There is no reliable prompt-level boundary. Treat document content as untrusted: escape or strip the delimiter tags inside uploads, limit what the model can do while processing documents (least-privilege tools, no secrets in context), require confirmation for side-effecting actions, and test with injection payloads.
