It will fail at construction: PyTorch raises ValueError because padding='same' isn't supported for strided convolutions. Keras gives ceil(56/2) = 28, so 28x28. Use padding=1 in PyTorch to get 28x28 too. The values will differ slightly from Keras with the same weights, though, because TensorFlow pads asymmetrically (extra row/column on the bottom/right); to match exactly, F.pad the input by (0, 1, 0, 1) and use padding=0.
