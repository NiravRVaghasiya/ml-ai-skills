An accuracy drop is not data drift by definition, and the fix is not the same for every cause. It could be data drift (the input distribution moved), concept drift (the relationship between inputs and labels changed), prediction drift (the output distribution shifted), or a plain bug, such as a broken upstream feature pipeline or a schema change. Diagnose before you retrain: compare feature statistics and the prediction distribution with the training window, and check predictions against ground truth as labels arrive. Retraining on last week's data cannot fix a pipeline bug and can hide it.
