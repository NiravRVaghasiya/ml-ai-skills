It's worth knowing that the IMDB test split is sorted by label, so a first-500 slice could in principle be a single class. But you also computed macro-F1, and a macro-F1 of 1.0 rules out the single-class problem because it averages the F1 of both classes equally - a constant predictor would score about 0.5. So the result is genuine. Shuffling before select() is good hygiene for next time, but there is no need to rerun this experiment.
