Not yet. Before it's safe to report anything, check the label distribution of both subsets with value_counts. The IMDB splits are stored sorted by label, so select(range(2000)) and select(range(500)) are each a single class, and a model that always predicts that class scores 1.0. Macro-F1 does not catch this: scikit-learn averages only over the labels present, so a one-class evaluation set still gives macro-F1 1.0. Shuffle with a fixed seed before subsetting (ds.shuffle(seed=42).select(range(2000))), retrain, and re-evaluate. It's only fine to report numbers once both subsets contain both classes.
